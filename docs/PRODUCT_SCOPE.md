# Product scope — 0.0.1-alpha

## Goal

Explore the identity, information architecture, and interaction patterns of Suyziss Synera before committing to a production backend or native Android implementation.

## Included in this prototype

- Responsive home feed with sample posts.
- Local post creation, appreciation/like toggle, and comments.
- Explore landing page and topic tiles.
- Profile overview and profile tabs.
- Sample notifications.
- Sample conversations and session-only outgoing messages.
- Light, dark, and system appearance preferences.
- Desktop sidebar, mobile bottom navigation, and responsive layouts.

## Not production features yet

- Authentication, registration, account recovery, or real profiles.
- Server persistence, multi-device sync, or real-time updates.
- Actual private messaging, encryption, delivery receipts, or attachments.
- Real media uploads, content moderation, reporting, blocking, and privacy controls.
- Push notifications, search indexing, recommendations, or administration.

## Design principles

1. Calm, premium, minimal visual language.
2. Light theme is the initial default; system preference is respected when selected.
3. Dark theme is designed as a first-class appearance, not an afterthought.
4. Responsive behavior must work on narrow mobile screens.
5. Interaction feedback should be immediate and understandable.
6. Product rules and API contracts must remain independent of the UI.
